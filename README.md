# Marca-INPI Adv-OS — Marketplace

Plugin Claude Code **full-stack de Direito Marcario** (marcas / INPI), de uso nacional.

## Instalacao (Claude Desktop / Cowork)
1. Abra o Claude Desktop → **Settings → Plugins → aba Pessoal**.
2. Clique em **"+" → Adicionar marketplace**.
3. Cole a URL deste repositorio.
4. Sincronize e instale o plugin **marca-inpi-adv-os**.
5. Rode **`/start-marca-inpi`** para configurar ao seu escritorio.

## O que entrega
Registro & consultivo (anterioridade, classificacao NCL, proposta/contrato por classe, deposito) + contencioso administrativo no INPI + contencioso judicial. 37 skills, orquestrador `marcas-master`, Suprema Corte R1-R4.
